About AndyAPI Client

This client connects your local AI models to the AndyAPI server via WebSocket, allowing them to be accessed through a unified API endpoint.

New Features:

  • Multiple Endpoints: Configure multiple OpenAI-compatible API endpoints (Ollama, OpenRouter, vLLM, etc.)
  • Model ID Mapping: Use different internal/external model IDs
  • Custom Headers & Params: Add extra headers and parameters per endpoint or model
  • Statistics Tracking: Monitor requests, latency, and token usage
  • Hot Reload: Config changes are automatically applied without restart
  • Configurable Timeouts: Set timeouts globally, per endpoint, or per model
